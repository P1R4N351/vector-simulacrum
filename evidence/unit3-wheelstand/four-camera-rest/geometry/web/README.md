# Photo-based cube markings in the shape renderer

The free cube's shape renderer draws the three adjacent stock markings visible together in the supplied close-up. Each border was rectified to a square, with the light ink isolated from the illuminated plastic. The nominal border spans 23 mm on the 44 mm body. These visual planes follow the simulated body's position and orientation. The upright face assignment presents the photographed front symbol to an approaching robot. Absolute registration to the cube accelerometer remains unknown. The three opposite faces are unmarked in this mode. With the optional SDK model installed, its full six-face atlas remains available.
