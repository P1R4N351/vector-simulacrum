# See3CAM shoulder comparison

Both original 1920 × 1080 exposures are rotated and rectified directly. The archived shelf distortion model maps the 1200 × 780 comparison crop into the native fisheye frame. All metrics use horizontal distances on the same rectified scanline. The printed rims supply the full pose fit with the 48 mm longitudinal spacing and 3.75 mm height difference. Ring 30 has only partial, dimly lit arcs. The low final RMS on its visible arcs understates pose uncertainty.

The pale yellow dots on the wheels mark the selected rim samples. In the shoulder zoom, magenta is the original mesh, cyan the revised mesh, and the dotted line the image edge. The plotted mesh contours come from scanline intersections with the triangulated shell. The right column shows differences from the original projection, in rectified pixels. The 25–75% image transition band measures how the selected edge moves with contrast threshold. The pose envelope repeats the rim fit with an alternate reading, smaller flat-face diameters, two camera calibration variants, arc omissions, and common ±2 pixel horizontal/vertical shifts. Neither envelope is a statistical confidence interval. For each scanline we compare the contour shift against the maximum absolute pose perturbation plus half the edge width. No tested row clears that bound. The archive records row-level values so other rules can be evaluated.

To replay, set `VECTOR_PHOTO_ORBIT` to the original archive containing `ring30-see1.jpg` and `ring150-see1.jpg`. Set `VECTOR_SHELL_EXPORTS` to the directory containing `pre.json` and `post.json` exported by `evidence/iphone-lidar-orbits/export-shell.mjs`. The supplied camera matrices in `evidence/hub-calibration-b` will be located automatically inside the evidence tree or supplied with `VECTOR_CALIBRATION_DIR`. Run `python analysis.py`, `python score.py`, and `python plot.py` with NumPy, SciPy, OpenCV, and Matplotlib installed.
